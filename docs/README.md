# Documentation / Документация

[Main README](../README.md) · [README на русском](../README.ru.md)

Every guide exists in English and Russian. The two versions describe the same app, so if one of them disagrees with the interface, the other is probably outdated too.

Каждый гайд есть на английском и на русском. Обе версии описывают одно и то же приложение, так что если одна расходится с интерфейсом, вторая, скорее всего, устарела тоже.
