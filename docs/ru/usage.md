# Как пользоваться приложением

[← Оглавление документации](../README.md)

Полный тур по интерфейсу, опция за опцией. Если нужно просто побыстрее закинуть текстуру в
игру, короткий путь описан в [Простых рескинах](reskin.md).

## Раскладка

Три колонки:

1. **Слева: что моддим** (Шаг 1). Таб-бар сверху переключает **Weapons**, **Hats** и
   **Diagnostics**.
2. **По центру: превью.** Слоты текстур (2D) и 3D-вид, который грузится по запросу.
3. **Справа: опции экспорта** (Шаг 2): разрешение, формат, имя файла, **Собрать** и раздел
   **Дополнительно**.

**Шестерёнка** в правом верхнем углу открывает [Настройки](#настройки). При переключении на
вкладку **Diagnostics** центральная и правая колонки полностью пропадают, остаётся только
список диагностики. Так и задумано: пока просто осматриваешь `.vpk`, Шагу 2 делать нечего.

## Шаг 1: выбор цели

### Вкладка Weapons (Оружие)

Выбираешь **Категорию**, поля под ней подстраиваются:

| Категория | Что собирает |
|-----------|--------------|
| **Оружие** | Стоковое оружие: Класс → Слот → Оружие |
| **Персонаж** | Части тела и руки вьюмодели (по классам), а также маски маскировки Шпиона |
| **Специальное** | Крит-эффект, спрей или эффект смерти (лёд / золото / огонь) |
| **Снаряд / Пикап / Насмешка** | Ракеты/стрелы, аптечки/патроны, реквизит насмешек |
| **Небо (Skybox)** | Замена неба, сразу на всех картах или для одного конкретного неба |
| **Кастомный** | `.vpk`-мод, загруженный в 3D-вид, чтобы осмотреть его или доработать |

Выбери **Персонаж → маска маскировки Шпиона**, и над тулбаром появится ряд маленьких кнопок по
классам. Каждая грузит маску того класса отдельно для перерисовки.

### Вкладка Hats (Шапки)

Тут всё богаче, чем можно подумать по короткому описанию. Сверху: **поисковая строка**,
фильтрующая список на лету, кнопка **обновить** (↺), которая перечитывает `items_game.txt` с
нуля (пригодится, если только что что-то поменял в установке TF2 и список выглядит устаревшим),
и кнопка-**фильтр** (иконка воронки) с тремя переключателями: **скрыть медали**, **скрыть
Halloween**, **скрыть сезонные** (Christmas и т.д.). Эти настройки запоминаются между запусками.
Ниже идёт ряд кнопок-классов, чтобы сузить список до одного класса.

Выбери шапку. Если у неё несколько **стилей** или она применяется к нескольким **классам**,
под списком откроется панель: ряд **«Стили для сборки»** (выбираешь один для редактирования,
точка отмечает стили с уже внесёнными правками) и ряд **«Классы для сборки»** (чекбоксы, хотя
бы один должен остаться включённым). Во время сборки спросят, накладывать ли **игровые
краски** на твою текстуру. По умолчанию да.

### Вкладка Diagnostics (Диагностика)

Кинь `.vpk` на вкладку (или нажми **Choose VPK**, после загрузки кнопка станет **Re-check**), и
приложение проверит его на типовые причины, почему мод не появляется в игре: нет
`$basetexture`, неверные пути, битые VTF. Результаты выглядят как цветные карточки: красный для ошибок,
жёлтый для предупреждений, зелёный для информационных, с указанием места и подсказкой, как
исправить.

## Шаг 2: тулбар превью

Кнопки появляются и прячутся в зависимости от того, что выбрано, так что не удивляйся, если
твой тулбар выглядит скромнее этого списка. Большинство кнопок показываются только когда
уместны.

| Контрол | Что делает |
|---------|-----------|
| **3D / 2D** | Переключение между 3D-моделью и плоским видом текстуры |
| **Куб** (*Load 3D model*) | Отрисовывает текущий выбор в 3D. **3D-вид сам никогда не грузится, жать нужно после выбора.** |
| **VPK** | Загрузить готовый `.vpk`-мод в 3D-вид, например, чтобы осмотреть его или доработать |
| **Замена модели** | Заменить модель на свою, полный процесс в [Кастомных моделях](custom-models.md) |
| **QC** | Открывает скрипт компиляции модели для правки. Появляется только у кастомных моделей, загруженных с «сохранить материалы» (риггнутых); у варианта «только геометрия» кнопки QC нет, там нечего править на уровне модели |
| **RED / BLU** | Появляются, если у предмета есть отдельные командные скины. Переключай команду и грузи текстуру для каждой |
| **`+`** | Появляется вместо RED/BLU, если в базовой игре у оружия нет командного варианта. Нажми, чтобы включить командный режим: появятся переключатели RED/BLU, а синий материал приложение соберёт само. Оставь BLU пустым, обе команды получат RED-текстуру |
| **Плашки стилей/скинов** | Для кастомных или заменённых моделей с несколькими скин-семействами внутри, по плашке на скин, чтобы назначить каждому свою текстуру |
| **Кнопка Australium** (золотая иконка) | Появляется, если приложение нашло золотой/Australium-вариант текущего оружия. Тумблер переключает превью и правку этого варианта отдельно от обычного |
| **Кнопка-глаз** (служебные текстуры) | Отдельная от Australium кнопка, появляется, если у модели есть скрытые «misc»-материалы (глаза, свечение убера и т.п.), которые стоит показать. Нажми, чтобы открыть их для опциональной замены |

Кидай изображения в **главный слот** или в любую из карточек доп. материалов в ряду под
тулбаром. Клик по самой карточке просто открывает выбор файла для этого материала. Чтобы
задать материалу *свои* разрешение, формат или флаги, кликай маленькую **иконку-шестерёнку** в
углу карточки. Это переключает Шаг 2 в режим пер-текстурного редактирования (появляется жёлтый
баннер); кнопка **Готово** возвращает к глобальным настройкам.

## Шаг 2: опции экспорта

| Опция | Пояснение |
|-------|-----------|
| **Разрешение** | 256 (Спрей) / 512 (Обычное) / 1024 (Высокое) / 2048 (Ультра) |
| **Формат** | Формат VTF (`DXT1`, `DXT5`, `RGBA8888`, …). Список сам сужается под то, что поддерживает текущий материал |
| **Имя файла** | Имя выходного `.vpk`: до 50 символов, без `\ / : * ? " < > \|` |
| **Собрать** | Запускает сборку и кладёт результат в папку экспорта |

### Раздел «Дополнительно»

- **VTF-флаги**: `Clamp S`, `Clamp T`, `No Mipmaps`, `No LOD`, `No minimum Mipmap`, а также
  `Normal Map`, `No Thumbnail`, `No Reflectivity` и `Gamma Correction` (со своим полем значения).
- **Material Maps…** *(только для моделей)*: скармливаешь обычную картинку, приложение само
  генерит правильно оформленный VTF и прописывает VMT, избавляя от угадывания форматов и путей
  вручную. Доступно семь типов карт: **detail-слой**, **самосвечение** (маска свечения),
  **Phong-карта** (блеск), **маска отражения** (хром против матового), **rim light** (мягкая
  обводка светом по краям), **Phong-warp** (подкрашивает блики вместо обычного белого) и
  **lightwarp** (меняет, как ложатся свет и тень: тот самый мультяшный вид TF2).
- **Редактировать VMT…**: ручная правка VMT выбранного материала прямо в приложении, с
  подсветкой синтаксиса и автодополнением `$параметров`. Меню **Вставить** добавляет частые
  параметры, прокси или целые шаблоны; **Сбросить до оригинала игры** отменяет все правки и
  возвращает игровой VMT. У каждого материала своя правка, независимая от остальных.
- **Изолировать плечи**: только для рук. Переименовывает материал руки/плеча, чтобы правка не
  затронула мирового персонажа.
- **Инструменты**: четыре кнопки, не меню.
  - *Extract Original Model (SMD)* декомпилирует текущее оружие и открывает чек-лист всех
    извлечённых файлов (reference SMD, LOD-ы и т.д.), чтобы выбрать, что сохранить.
  - *Export UV Template (PNG)* даёт плоскую UV-развёртку, чтобы рисовать поверх.
  - *Extract Original Texture*: для скинов персонажа открывает окно с превью всех VTF в папке
    этого персонажа; для остального просто забирает текущий материал.
  - *Сборка в один* (Merge into One) объединяет несколько собранных модов в один `.vpk`.
    Выбираешь моды, задаёшь имя результата, и если одно и то же оружие встречается больше чем в
    одном из них, предупредят, прежде чем что-то перезапишется.

## Сборка и установка

1. Нажми **Собрать**. Покажется прогресс, и по ходу приложение может кое-что спросить, см.
   ниже.
2. Готовый `<имя>.vpk` окажется в **папке экспорта** (`export/` по умолчанию).
3. Скопируй его в `…\Team Fortress 2\tf\custom\` и перезапусти TF2.
4. Чтобы убрать мод, удали его `.vpk` из `tf\custom\` и перезапусти.

Что приложение может спросить во время сборки:

- **У материала ещё нет текстуры**: выбирай *Upload mine*, *Use game original* или *Use main
  texture* (по умолчанию). Отметь *apply to all remaining*, если хочешь один и тот же ответ для
  всех оставшихся материалов. Если для этого слота текстура уже загружена через карточку,
  вопроса вообще не будет, приложение просто возьмёт то, что уже дано.
- **У оружия есть доп. часть модели** (гильза, линза прицела…): спросят, заменять ли и её.
  Ответ **Нет** оставляет оригинальную игровую часть, обычно это и нужно.
- **Только для сборок с сохранением материалов:** если число текстур не совпадает с ожидаемым,
  приложение предупредит до упаковки, чтобы можно было отменить и проверить модель, а не
  выпустить сломанный мод.

> **`sv_pure`:** многие серверы блокируют клиентские скины в принципе. Проверяй локально или на
> сервере, где они точно разрешены, прежде чем решать, что мод сломан. Настройка **sv_pure
> bypass** лишь меняет, в какую папку кладутся материалы *модели*. Это не гарантия против
> правил конкретного сервера.

## Настройки

Открываются шестерёнкой справа сверху. Это одно прокручиваемое окно с подписанными разделами,
а не настоящие вкладки:

- **Пути**: **Папка игры TF2** (должна содержать `tf/` и `bin/`) и **Папка экспорта**.
- **Предпочтения**: **Язык** (English / Русский), **Формат экспорта** (формат изображения при
  *извлечении* текстуры, отдельно от формата VTF при сборке в Шаге 2), **Тема** (Dark / Blue) и
  **sv_pure bypass** (`console\` по умолчанию или `vgui\replay\thumbnails\`).
- **Разработчик**: **Keep temp files** и **Debug mode** (включай перед тем, как оформлять
  багрепорт), **Clear Model Cache** (удаляет кэш декомпилированных моделей, спросит
  подтверждение и покажет, сколько места освободится; используй после обновления TF2, если
  сборки начали падать) и **Material blacklist** (паттерны материалов, скрываемых везде; по
  одному на строку, префикс `=` даёт совпадение точно по имени, а не по подстроке).
- **Support**: ссылка на Steam-страницу разработчика для обмена, если хочется сказать спасибо.
