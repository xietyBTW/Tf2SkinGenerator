# Как пользоваться приложением

[← Оглавление документации](../README.md)

Полный тур по интерфейсу и всем опциям сборки. Быстрый путь под конкретную задачу — см.
[Простые рескины](reskin.md).

## Раскладка

Окно состоит из трёх колонок:

1. **Слева — что моддим** (Шаг 1). Таб-бар переключает **Weapons**, **Hats** и **Diagnostics**.
2. **По центру — превью.** Слоты текстур (2D) и 3D-вид по запросу.
3. **Справа — опции экспорта** (Шаг 2): разрешение, формат, имя файла, **Собрать** и раздел
   **Дополнительно**.

**Шестерёнка** (справа сверху) открывает [Настройки](#настройки).

## Шаг 1 — выбор цели

### Вкладка Weapons (Оружие)

Выбери **Категорию**, поля ниже подстраиваются:

| Категория | Что собирает |
|-----------|--------------|
| **Оружие** | Стоковое оружие — Класс → Слот → Оружие |
| **Персонаж** | Части тела и руки вьюмодели (по классам); маски маскировки Шпиона |
| **Специальное** | Крит-эффект, спрей или эффекты смерти (лёд / золото / огонь) |
| **Снаряд / Пикап / Насмешка** | Ракеты/стрелы, аптечки/патроны, реквизит насмешек |
| **Небо (Skybox)** | Замена неба (все карты сразу или одно именованное небо) |
| **Кастомный** | `.vpk`-мод, загруженный в 3D-вид |

### Вкладка Hats (Шапки)

Листаешь косметику, выбираешь одну и (по желанию) редактируешь **по классам** и **по стилям**. Во
время сборки спросят, должны ли на твою текстуру накладываться **игровые краски**.

### Вкладка Diagnostics (Диагностика)

Загрузи готовый `.vpk`-мод — приложение осмотрит его на типовые проблемы (нет `$basetexture`,
неверные пути, проблемы VTF). Полезно, когда мод «не появляется» в игре.

## Шаг 2 — превью

В центральной колонке есть тулбар:

| Контрол | Что делает |
|---------|-----------|
| **3D / 2D** | Переключение между 3D-моделью и плоским видом текстуры |
| **Куб** — *Load 3D model* | **Отрисовывает текущее оружие в 3D. 3D-вид сам не грузится — жми после выбора.** |
| **VPK** | Загрузить готовый `.vpk`-мод в 3D-вид |
| **🔄** | Заменить модель на свою (см. [Кастомные модели](custom-models.md)) |
| **QC** | Правка QC-скрипта модели (продвинутое, для кастомных моделей) |
| **RED / BLU** | Появляются, если у предмета есть командные скины — переключай команду и грузи свою текстуру |
| **`+`** | Появляется для оружия **без** командного варианта — добавить отдельную BLU-текстуру |
| **Australium** / **глаз** | Тумблер золотого варианта; служебные текстуры (глаза, убер и т.п.) |

Кидай изображения в **главный слот** и в **карточки доп. материалов**. Клик по карточке материала
переводит Шаг 2 в **режим пер-текстурного редактирования** (появляется жёлтый баннер) — можно
задать этому материалу своё разрешение/формат/флаги; кнопка **Готово** возвращает к глобальным.

## Шаг 2 — опции экспорта

| Опция | Пояснение |
|-------|-----------|
| **Разрешение** | 256 (Спрей) / 512 (Обычное) / 1024 (Высокое) / 2048 (Ультра) |
| **Формат** | Формат VTF (`DXT1`, `DXT5`, `RGBA8888`, …). Список сам сужается под текущий режим. |
| **Имя файла** | Имя выходного `.vpk` (до 50 символов, без `\ / : * ? " < > \|`). |
| **Собрать** | Запускает сборку; результат — в папку экспорта. |

### Раздел «Дополнительно»

- **VTF-флаги** — `Clamp S`, `Clamp T`, `No Mipmaps`, `No LOD`, `No minimum Mipmap`, а также
  `Normal Map`, `No Thumbnail`, `No Reflectivity` и `Gamma Correction` (со значением).
- **Material Maps…** — добавить detail / самосвечение / phong-карты из изображений; приложение
  соберёт VTF и пропишет VMT. (Только для моделей.)
- **Редактировать VMT…** — ручная правка VMT выбранного материала. У каждого материала своя правка.
- **Изолировать плечи** — только для рук; переименовывает материал руки/плеча, чтобы правка не
  затронула мирового персонажа.
- **Инструменты** — *Extract Original Model (SMD)*, *Export UV Template (PNG)*, *Extract Original
  Texture* и *Merge VPK* (объединить несколько модов в один).

## Сборка и установка

1. Нажми **Собрать**. Показывается прогресс; по ходу приложение может спросить про доп.
   материалы/части.
2. Готовый `<имя>.vpk` окажется в **папке экспорта** (`export/` по умолчанию).
3. Скопируй его в `…\Team Fortress 2\tf\custom\` и перезапусти TF2.
4. Чтобы убрать мод — удали его `.vpk` из `tf\custom\` и перезапусти.

> **`sv_pure`:** многие серверы блокируют клиентские скины. Проверяй локально или на серверах, где
> они разрешены. Опция **sv_pure bypass** в Настройках лишь влияет на то, в какую папку кладутся
> материалы *модели* — это не гарантия.

## Настройки

Открываются шестерёнкой (справа сверху).

- **Пути** — **Папка игры TF2** (должна содержать `tf/` и `bin/`) и **Папка экспорта**.
- **Предпочтения** — **Язык** (English / Русский), **Формат экспорта**, **Тема** (Dark / Blue),
  **sv_pure bypass** (`console\` по умолчанию или `vgui\replay\thumbnails\`).
- **Разработчик** — **Keep temp files** и **Debug mode** (для отладки/багрепортов), **Clear Model
  Cache** (удалить кэш декомпилированных моделей — если после обновления TF2 сборка сломалась) и
  **Material blacklist** (паттерны материалов, которые никогда не показывать и не писать; по одному
  на строку, префикс `=` — точное имя).
