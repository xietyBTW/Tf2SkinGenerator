# Простые рескины

[← Оглавление документации](../README.md)

«Рескин» оставляет стоковую модель оружия и меняет только её **текстуру**. Это самый быстрый вид
мода и лучшая точка старта.

## Перед началом

- TF2 должен быть установлен, а **папка игры** — указана в Настройках (см.
  [главный README](../README.ru.md#первичная-настройка)).
- Подготовь текстуру в формате `PNG`, `JPG`, `TGA`, `BMP` или готовый `VTF`.
- Не знаешь размер/раскладку? Сначала загрузи оружие, выгрузи из превью его **UV‑шаблон** и рисуй
  поверх него.

## Шаги

1. **Выбери оружие.** В левой панели: **Категория → Оружие**, затем
   **Класс → Слот (Основное / Вторичное / Ближний бой) → Оружие**.

2. **Покажи оружие в 3D (опционально).** 3D‑вид **не** загружается автоматически. В тулбаре превью
   нажми **кнопку-куб** (*Load 3D model*), чтобы отрисовать выбранное оружие. 2D‑вид обновляется
   сам. Кнопки тулбара:

   | Кнопка | Что делает |
   |--------|-----------|
   | **3D / 2D** | Переключение между 3D‑моделью и плоским 2D‑видом текстуры |
   | **Куб** (*Load 3D model*) | Отрисовывает текущее оружие в 3D — жми после выбора |
   | **VPK** | Загрузить готовый `.vpk`‑мод в 3D‑вид |
   | **Замена модели** | Подставить свою модель (см. [Кастомные модели](custom-models.md)) |

3. **Загрузи текстуру.** Перетащи изображение в **главный слот текстуры** (или нажми Browse на
   слоте). Превью отреагирует сразу.

   - У модели могут быть **доп. материалы** (линза прицела, гильза и т.д.). Текстуры для них можно
     заранее загрузить в карточки доп. слотов либо ответить на вопрос во время сборки
     (*Загрузить свою / Использовать обычную / Использовать основную*).

4. **Командные текстуры RED / BLU.**

   - Если у оружия уже есть отдельные командные скины, в тулбаре появляются переключатели **RED**
     и **BLU**. Переключись на **BLU** и загрузи вторую текстуру для синей команды.
   - Если в базовой игре у оружия **нет** командного варианта, вместо этого появляется кнопка
     **`+`** (*Сделать оружие командным: добавить отдельную BLU‑текстуру*). Нажми её, чтобы включить
     командный режим — появятся переключатели RED/BLU, а синий материал приложение синтезирует при
     сборке. Оставь BLU пустым, чтобы использовать RED‑текстуру для обеих команд.
   - У некоторых видов оружия есть ещё тумблер **Australium/Gold** и **кнопка-глаз** для служебных
     текстур (глаза, убер и т.п.).

5. **Задай параметры вывода** справа:

   | Параметр | Пояснение |
   |----------|-----------|
   | **Разрешение** | 256 / 512 / 1024 / 2048. Больше = чётче и тяжелее файл. |
   | **Формат** | `DXT1` (без альфы) или `DXT5` (с альфой / прозрачностью). |
   | **VTF‑флаги** | `Clamp S/T`, `No Mipmaps`, `No LOD` — оставь по умолчанию, если не знаешь, зачем менять. |
   | **Имя файла** | Имя выходного `.vpk`. |

6. **Собери.** Нажми **Собрать**. Приложение сконвертирует текстуру в VTF, запишет VMT, упакует
   всё и положит `<имя>.vpk` в **папку экспорта** (`export/` по умолчанию).

## Установка мода в игру

1. Скопируй собранный `.vpk` в:
   ```
   …\Steam\steamapps\common\Team Fortress 2\tf\custom\
   ```
   (Создай папку `custom`, если её нет.)
2. Перезапусти TF2 (именно полный перезапуск — надёжнее всего).
3. Возьми оружие и проверь его в лоадауте / на карте.

> **Удаление мода:** удали его `.vpk` из `tf\custom\` и перезапусти игру.

## Если что‑то не так

- **Оружие стоковое / розово‑чёрная клетка** — VPK не в `tf\custom\` либо пути внутри не совпадают
  с оружием. Пересобери и перекопируй.
- **Непонятно, почему не применяется** — открой вкладку **Диагностика** и загрузи свой `.vpk`; она
  подсветит типовые проблемы (нет `$basetexture`, неверные пути, проблемы VTF).
- **Серверы с `sv_pure`** — многие серверы блокируют клиентские скины. Проверяй на локальном
  сервере или казуале/комьюнити‑сервере, где они разрешены.
