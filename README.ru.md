# TF2 Skin Generator

> **Язык:** Русский · [English](README.md)

Десктоп-приложение под Windows для сборки **VPK-модов скинов Team Fortress 2** без командной
строки. Выбираешь оружие (или шапку, часть персонажа, небо…), кидаешь свою текстуру, и на
выходе `.vpk`, который можно сразу класть в игру. Конвертацию VTF, генерацию VMT,
декомпиляцию/компиляцию модели и упаковку приложение берёт на себя.

## Возможности

- **Рескины оружия**: заменить текстуру любого стокового оружия.
- **Кастомные модели**: заменить саму геометрию (декомпиляция, затем компиляция через Crowbar +
  `studiomdl`).
- **Шапки**: список косметики с поиском и фильтрами, редактирование по классам и по стилям,
  опциональная поддержка игровых красок.
- **Части персонажа**: тела и руки вьюмодели, маски маскировки Шпиона, изоляция плеч.
- **Особые скины**: крит-эффекты, спреи, эффекты смерти (лёд / золото / огонь).
- **Небо (skybox)**: замена неба из панорамы или шести граней, с 3D-превью.
- **Снаряды, пикапы, реквизит насмешек.**
- **Живое 2D- и 3D-превью** до самой сборки.
- **Вкладка «Диагностика»**: загружаешь готовый `.vpk`, приложение подсвечивает типовые
  причины, почему мод не появляется в игре.
- Интерфейс на английском / русском.

## Требования

- **Windows** (в комплекте `vpk.exe`, `VTFCmd`, Crowbar; для компиляции моделей используется
  `studiomdl.exe` из установленной игры).
- **Установленный Team Fortress 2**, нужен для сборки. Приложение читает файлы игры и вызывает
  `<TF2>/bin/studiomdl.exe` для компиляции моделей.
- Для запуска из исходников: **Python 3.12+**.

## Установка и запуск

### Вариант A: готовая сборка (для пользователей)

1. Скачай последний релиз со
   [страницы Releases](https://github.com/xietyBTW/Tf2SkinGenerator/releases/latest).
2. Запусти установщик либо распакуй портативную сборку и открой `Tf2SkinGenerator.exe`.

### Вариант B: из исходников (для разработчиков)

```bat
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python main.py
```

Сторонние тулзы (Crowbar, VTF-тулзы) уже лежат в `tools/`, качать для них ничего не нужно.
Единственное исключение и остальная настройка окружения описаны в
[docs/ru/building-from-source.md](docs/ru/building-from-source.md).

## Первичная настройка

1. Запусти приложение и открой **Настройки** (шестерёнка справа сверху).
2. Укажи **папку игры TF2**, ту, где лежат `tf/` и `bin/`
   (например, `…\steamapps\common\Team Fortress 2`).
3. При желании выбери язык интерфейса и папку экспорта по умолчанию.

## Быстрый старт (30 секунд)

1. **Категория → Оружие**, затем слева выбери класс → слот → оружие.
2. Кинь свою текстуру в главный слот в центральном превью.
3. Справа задай разрешение / формат / имя файла и нажми **Собрать**.
4. Скопируй готовый `.vpk` из папки `export/` в
   `…\Team Fortress 2\tf\custom\` и перезапусти игру.
